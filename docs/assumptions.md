# この課題で置く前提

課題に書かれた条件と、自分たちで決めた条件を分けて記録する。

## 課題に書かれていること

- 変圧器の油温を予測し、運用や保全に役立つかを調べる。
- 不明な点は、筋の通った仮定を置き、その内容を説明する。
- データを追加する場合は、入手元を示す。

## 初期検証の条件

| 項目 | 内容 | 理由 |
|---|---|---|
| 使うデータ | まずETTh1 | 1時間ごとで、最初の分析を進めやすい |
| 予測するもの | 1時間先の油温（OT） | まず次の1点を予測するところから始める |
| 使ってよい情報 | 予測を出す時点までに観測した負荷と油温 | 未来の実測値を知らなくても予測できるようにする |
| データの分け方 | 学習12か月、検証6か月、テストは残り約6か月 | 過去から未来を予測する状況に合わせる |

例えば、10時の観測が終わったら、10時までの情報で11時の油温を予測する。
そのため、現在の油温と負荷を、毎時間取得できると仮定する。

## まだ分からないこと

- 1時間前に油温が分かることで、現場がどのような対応を取れるか。
- 何度から危険なのか。データだけで安全基準を決めることはできない。
- 別の変圧器のデータでも、同じ方法が役立つか。

予測方法と評価の説明は[モデルの比較計画](modeling_plan.md)にまとめる。
