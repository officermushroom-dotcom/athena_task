# 検証の前提

変圧器の油温（CSVの `OT`）を予測し、運用・保全の判断に役立つ見通しを出せるか調べた。不明な条件は仮定として明記し、追加データを使う場合は出典を示す。

## 予測時に使える情報

予測を出す時点までの観測値を利用できると仮定する。例えば10:00に11:00の油温を予測する場合、当日の10:00までの油温を使う。負荷を加えた実験でも、予測時点までに観測した負荷を使った。

観測間隔はETThが1時間、ETTmが15分。ETTmの1時間先予測は4行先に当たる。番号が同じ1時間版と15分版は同じ観測対象なので、別の設備で再現した結果とは数えない。

最初はETTh1で検証し、他系列や予測時間でも比較した。最終テストの対象は **ETTm2の1時間先の油温**。15分間隔で取得した予測時点までの油温を、直近1日分または7日分使った。期間の分け方と評価方法は[モデルの比較計画](modeling_plan.md)に記載する。

## 高温と急上昇の扱い

- **高温への到達**：初期の探索では、学習期間の油温の90パーセンタイルを目安に、油温がその値に達するか調べた。ETTh1の検証期間では到達が0件で、見逃しを評価できなかった。
- **急上昇**：予測時点から予測対象時刻までの油温上昇幅を使う。学習期間の上昇幅の90パーセンタイルを基準にし、評価期間では固定する。ETTm2の1時間先の最終テストでは約+1.758以上を急上昇とした。

どちらもデータに基づく実験用の基準。対象設備の安全基準、警報設定、担当者の対応に必要な時間は未確認。最終テストで評価したのは油温の誤差と急上昇時の過小予測量で、実機の警報としての性能は別途検証が必要。
