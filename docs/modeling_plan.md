# モデルの比較計画

初期の比較から、ETTm2の1時間先予測の最終テストまでの条件をまとめる。各実験の数値は[実験記録](experiment_log.md)を参照。

## 1. データをどう分けたか

予測対象の日時を基準に、古い順に分けた。例えばテスト期間の初回の予測でも、その時点で観測済みの前年の油温は入力に使える。

| 区分 | 期間 | 役割 |
|---|---|---|
| 学習 | 2016年7月〜2017年6月 | モデルの重みを学ぶ |
| 検証 | 2017年7月〜12月 | 入力やモデルを比較する |
| 最終テスト | 2018年1月〜データ末尾 | 選んだ方法が別期間でも通用するか確かめる |

学習期間を15か月に延ばす実験では、2017年7〜9月を追加し、12か月・15か月のモデルを共通の10〜12月で比較した。最終テストでは最初の12か月で学習したモデルを使った。

## 2. 何と何を比較したか

- **持続予測**：予測時点の油温をそのまま未来の予測値にする。油温は直前の値と強く関係するため、比較の基準にした。
- **Ridge回帰**：現在と過去の油温などに重みを付け、足し合わせて予測する。似た動きをする入力が多いので、重みが大きくなりすぎるのを抑える仕組みを使った。実験ではその強さを表す alpha を1.0に固定した。
- **追加実験**：油温や負荷をどの時刻から入れるか、学習期間、予測する先の長さを比較した。LightGBMも、同じ入力と学習・検証行でRidgeと比較した。

ETTm2の1時間先予測では、直近1日・7日・14日の油温履歴を同じ条件で比べ、検証MAEが最も小さかった7日分を主候補にした。1日分でも近い結果だったため、最終テストでは持続予測・1日分のRidge（96点）・7日分のRidge（672点）を比較した。Ridgeは同じ34,365件で学習し、同じ16,976件で評価した。

## 3. 予測の良し悪しをどう測ったか

| 指標 | 意味 |
|---|---|
| MAE（主指標） | 予測が実測から外れた幅の平均。 |
| RMSE | 誤差を二乗して平均し、平方根を取った値。大きな外れをより重く見る。 |
| 平均過小予測量 | 実測より低く予測した場合はその差、実測以上なら0として、対象の全件で平均する。 |
| 予測値 − 実測値の平均 | 負なら低め、正なら高めに予測した傾向を示す。高めと低めの誤差は打ち消し合う。 |

最終テストでは全件の誤差に加え、学習期間で決めた上昇幅の基準に当てはまる急上昇1,829件でも、実測を下回った幅を比較した。急上昇を何件通知できるかは、一部の検証実験で見逃しと誤報を集計した。最終テストで示す過小予測量と、通知の検知率は別の指標。
