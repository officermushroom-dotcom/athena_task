# モデルの比較計画

初期検証の方針と、その理由をまとめる。モデルの実装・評価は今後行う。

## 1. 何を予測するか

今までに観測した負荷と油温を使って、1時間先の油温を予測する。
油温はCSVのOTという列に入っている。

例えば、10時の観測が終わったら、10時までの情報で11時の油温を予測する。
11時の実際の負荷や油温は、予測の入力に使わない。

最初はETTh1を使う。1時間ごとのデータなので、次の1点を予測するところから始めやすい。
ただし、1時間前に分かれば実際の保全に十分かどうかは、まだ分からない。

## 2. データをどう分けるか

| 区分 | 期間 | 役割 |
|---|---|---|
| 学習 | 2016年7月〜2017年6月 | モデルに関係性を学ばせる |
| 検証 | 2017年7月〜12月 | モデルや設定を選ぶ |
| テスト | 2018年1月〜データ末尾 | 最後に予測の実力を確認する |

古いデータから新しいデータへ、順番を混ぜずに分ける。
実際に使うときも、過去のデータで学んで未来を予測するため。
最初の12か月を学習に使うのは、夏と冬の両方を含めたいから。

検証データを見て設定を選び、テストデータは最後の確認に使う。
テストを見ながら何度も作り直すと、初めて見るデータでどれくらい当たるかが分からなくなる。

検証とテストでは季節が違う。誤差の違いを理解するため、月ごとの結果も確認する予定。

## 3. 予測の良し悪しをどう測るか

### MAE：平均してどれくらい外れたか

誤差のプラス・マイナスを取り除き、平均する。
例えば、誤差が1、1、4なら、MAEは (1 + 1 + 4) / 3 = 2。
小さいほどよい。

モデルを選ぶときは、検証データのMAEを主な基準にする。
平均的にどれくらい外れるかを説明しやすいから。

### RMSE：大きく外した予測も確認する

誤差を二乗して平均し、その平方根を取る。
誤差が1、1、4なら、RMSEは √((1² + 1² + 4²) / 3) ≒ 2.45。
小さいほどよく、MAEより大きな誤差の影響を強く受ける。

どちらも、高く予測したか低く予測したかは区別しない。
高温を低く予測する問題は、後で別に確認する。具体的な方法は未決定。

## 4. 何と何を比較するか

### 比較の基準：持続予測

1時間先も、現在と同じ油温だと予測する。
現在の油温が20なら、予測値も20。学習は必要ない。

最初のデータ分析では、油温は直前の値と強く関係していた。
そこで、この単純な方法を比較の基準にする。この基準をベースラインと呼ぶ。

### 最初の学習モデル：油温の履歴を使うRidge回帰

現在や過去の油温に重みを付けて、1時間先の油温を予測する。

```text
1時間先の油温
＝ 現在の油温 × 重み①
 ＋ 1時間前の油温 × 重み②
 ＋ 2時間前の油温 × 重み③
 ＋ 定数
```

これは仕組みを示す例。何時間前まで使うかは、これから決める。
重みは学習データから求める。

Ridge回帰には、重みが大きくなりすぎるのを抑える仕組みがある。
過去の油温同士のように、似た動きをする入力が多いとき、重みの決まり方を安定させる狙いがある。

まず油温だけで試し、持続予測より改善するかを見る。
負荷を加える比較はその次の候補で、まだ実装しない。
